# Integrating Amazon SageMaker with $CLOUD_LONG

[Amazon SageMaker AI][Amazon Sagemaker] is a fully managed machine learning (ML) service. With SageMaker AI, data scientists and developers can quickly and confidently build, train, and deploy ML models into a production-ready hosted environment.

This page shows you how to integrate Amazon Sagemaker with $SERVICE_LONG.

## Prerequisites

<IntegrationPrereqs />

* Setup an [AWS Account][aws-sign-up]
* [Install the latest version of AWS CLI][install-aws-cli]
* [Install Python][install-python]
* [Install psql cli][install-postgresql](Optional)

## Create a table in $SERVICE_LONG

Create a table in $SERVICE_LONG for storing model predictions generated by SageMaker.

<Procedure>

1. **Use the `psql` CLI or [$CONSOLE][console] to create a table for your time-series data**

   ```sql
   CREATE TABLE model_predictions (
         time TIMESTAMPTZ NOT NULL,
         model_name TEXT NOT NULL,
         prediction DOUBLE PRECISION NOT NULL
   );
   ```

1. **Convert the table to a hypertable for better performance**

   ```sql
   SELECT create_hypertable('model_predictions', 'time');
   ```

</Procedure>

## Set up Amazon SageMaker for integration with $CLOUD_LONG

<Procedure>

1. **Create a SageMaker notebook instance**

   * Open the AWS Management Console and navigate to SageMaker.
   * Create a new notebook instance with appropriate permissions to access $CLOUD_LONG and other required AWS resources.
   * Make sure the notebook is in a VPC or has the appropriate network access to connect with $CLOUD_LONG.

1. **Enable PostgreSQL connection between Sagemaker and $CLOUD_LONG**

   * Open a Jupyter notebook in your SageMaker instance and install psycopg2 PostgreSQL driver to enable database connectivity:

      ```bash
      !pip install psycopg2-binary
      ```

1. **Write a SageMaker script for database integration into $CLOUD_LONG**

   * Create a Python script to insert model predictions into $CLOUD_LONG:

      ```python
      import psycopg2
      from datetime import datetime

      def insert_prediction(model_name, prediction, host, port, user, password, dbname):
            conn = psycopg2.connect(
               host=host,
               port=port,
               user=user,
               password=password,
               dbname=dbname
            )
            cursor = conn.cursor()

            query = """
               INSERT INTO model_predictions (time, model_name, prediction)
               VALUES (%s, %s, %s);
            """

            values = (datetime.utcnow(), model_name, prediction)
            cursor.execute(query, values)
            conn.commit()

            cursor.close()
            conn.close()

      # Example usage
      insert_prediction(
            model_name="example_model",
            prediction=0.95,
            host="<TIMESCALE_HOST>",
            port=5432,
            user="<TIMESCALE_USER>",
            password="<TIMESCALE_PASSWORD>",
            dbname="<TIMESCALE_DB>"
      )
      ```

1. **Test the integration script between Sagemaker and $CLOUD_LONG**

   * Run the script in your SageMaker notebook to verify data insertion into $CLOUD_LONG.

</Procedure>

## Automate data ingestion from SageMaker models

Once you've tested the basic integration, you can automate the ingestion of model predictions into $CLOUD_LONG as part of your SageMaker workflows.

<Procedure>

1. **Integrate the script into a SageMaker pipeline**
   * Modify your SageMaker training or inference pipeline to call the database integration script after predictions are generated.

1. **Schedule predictions and data ingestion**
   * Use SageMaker processing jobs or batch transform to generate predictions at regular intervals.
   * Ensure the predictions are inserted into $CLOUD_LONG using the integration script.

</Procedure>

## Query and visualize data in $CLOUD_LONG

<Procedure>

1. **Query model outputs in [$CONSOLE][console]**

   * Use SQL queries to analyze model predictions stored in $SERVICE_LONG:

      ```sql
      SELECT * FROM model_predictions
      WHERE model_name = 'example_model'
      ORDER BY time DESC;
      ```

1. **Visualize data by connecting visualization tools with $CLOUD_LONG**

   * Integrate visualization tools like [Grafana][grafana-integration] or [Tableau][tableau-integration] with $CLOUD_LONG to create real-time dashboards of your model predictions.

</Procedure>

Now you can seamlessly integrate Amazon SageMaker with $CLOUD_LONG to store and analyze time-series data generated by machine learning models.
