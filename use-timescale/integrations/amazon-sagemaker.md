# Integrating Amazon SageMaker with Timescale Cloud

This guide demonstrates how to integrate Amazon SageMaker with Timescale Cloud to store, analyze, and visualize time-series data generated by machine learning models. Amazon SageMaker provides a managed platform for building, training, and deploying machine learning models. Timescale Cloud offers a scalable and reliable platform for managing time-series data.

---

## Prerequisites

Before you begin, ensure you have the following:

1. **AWS Account**: An active AWS account with permissions to create and manage SageMaker resources.
2. **Timescale Cloud Account**: A Timescale Cloud account with a database provisioned.
3. **Database Connection Details**: Timescale Cloud connection details, including:
   - Host
   - Port
   - Username
   - Password
   - Database name
4. **AWS CLI**: Installed and configured. [Install AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/install-cliv2.html).
5. **Python Installed**: Ensure Python is installed for developing SageMaker processing scripts.
6. **psql CLI**: (Optional) Installed for testing database connectivity.

---

## Step 1: Set Up Your Timescale Cloud Database

1. **Create a Timescale Cloud Account**
   - Sign up for a Timescale Cloud account at [Timescale Cloud](https://www.timescale.com/).
   - Follow the instructions to provision a database.

2. **Note Database Connection Details**
   - Access your database connection information from the Timescale Cloud console.
   - Make a note of the following values:
      - Host
      - Port
      - Username
      - Password
      - Database name

3. **Create a Table for Storing Model Outputs**
   - Use the `psql` CLI or Timescale Cloud console to create a table for your time-series data:
     ```sql
     CREATE TABLE model_predictions (
         time TIMESTAMPTZ NOT NULL,
         model_name TEXT NOT NULL,
         prediction DOUBLE PRECISION NOT NULL
     );
     ```
   - Convert the table to a hypertable for better performance:
     ```sql
     SELECT create_hypertable('model_predictions', 'time');
     ```

---

## Step 2: Set Up Amazon SageMaker for Integration

1. **Create a SageMaker Notebook Instance**
   - Open the AWS Management Console and navigate to SageMaker.
   - Create a new notebook instance with appropriate permissions to access Timescale Cloud and other required AWS resources.

2. **Install Required Libraries**
   - Open a Jupyter notebook in your SageMaker instance and install the PostgreSQL library:
     ```bash
     !pip install psycopg2-binary
     ```

3. **Write a SageMaker Script for Database Integration**
   - Create a Python script to insert model predictions into Timescale Cloud:
     ```python
     import psycopg2
     from datetime import datetime

     def insert_prediction(model_name, prediction, host, port, user, password, dbname):
         conn = psycopg2.connect(
             host=host,
             port=port,
             user=user,
             password=password,
             dbname=dbname
         )
         cursor = conn.cursor()

         query = """
             INSERT INTO model_predictions (time, model_name, prediction)
             VALUES (%s, %s, %s);
         """

         values = (datetime.utcnow(), model_name, prediction)
         cursor.execute(query, values)
         conn.commit()

         cursor.close()
         conn.close()

     # Example usage
     insert_prediction(
         model_name="example_model",
         prediction=0.95,
         host="<TIMESCALE_HOST>",
         port=5432,
         user="<TIMESCALE_USER>",
         password="<TIMESCALE_PASSWORD>",
         dbname="<TIMESCALE_DB>"
     )
     ```

4. **Test the Integration Script**
   - Run the script in your SageMaker notebook to verify data insertion into Timescale Cloud.

---

## Step 3: Automate Data Ingestion from SageMaker Models

1. **Integrate the Script into a SageMaker Pipeline**
   - Modify your SageMaker training or inference pipeline to call the database integration script after predictions are generated.

2. **Schedule Predictions and Data Ingestion**
   - Use SageMaker processing jobs or batch transform to generate predictions at regular intervals.
   - Ensure the predictions are inserted into Timescale Cloud using the integration script.

---

## Step 4: Query and Visualize Data in Timescale Cloud

1. **Query Model Outputs**
   - Use SQL queries to analyze model predictions stored in Timescale Cloud:
     ```sql
     SELECT * FROM model_predictions
     WHERE model_name = 'example_model'
     ORDER BY time DESC;
     ```

2. **Visualize Data**
   - Use visualization tools like Grafana or Tableau to create dashboards for your model predictions.
   - Connect these tools to Timescale Cloud using your database credentials.

## Troubleshooting

1. **Connection Issues**
   - Verify your SageMaker instance has network access to Timescale Cloud.
   - Confirm that your Timescale Cloud database accepts connections from SageMaker.

2. **Data Insertion Errors**
   - Check the SageMaker notebook logs for error messages.
   - Ensure database credentials are correct and the target table exists.
