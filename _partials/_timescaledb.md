$TIMESCALE_DB is an extension for $PG that enables time-series workloads, 
increasing ingest, query, storage and analytics performance. 

Best practice is to run $TIMESCALE_DB in a [$SERVICE_LONG][service_long], but if you want to 
self-host you can run $TIMESCALE_DB yourself.


[service_long]: https://console.cloud.timescale.com/signup
