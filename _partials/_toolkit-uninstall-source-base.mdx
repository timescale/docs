## Uninstall $TOOLKIT_LONG

If you installed $TOOLKIT_SHORT by building from source, you can uninstall it without removing $TIMESCALE_DB or $PG.

<Procedure>

1.  **Drop the $TOOLKIT_SHORT extension from your databases**

    Connect to each database where $TOOLKIT_SHORT is enabled and remove the extension:

    <Tabs label="Connect to database" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
    ```

    </Tab>

    <Tab title="Windows" label="windows">

    ```powershell
    psql -U postgres -d <database_name>
    ```

    </Tab>

    </Tabs>

    At the `psql` prompt:

    ```sql
    DROP EXTENSION IF EXISTS timescaledb_toolkit CASCADE;
    ```

    Repeat this for all databases with $TOOLKIT_SHORT enabled. To exit psql, type `\q`.

    <Highlight type="warning">

    Using `CASCADE` will drop all objects that depend on the $TOOLKIT_SHORT extension. Ensure you have backed up any data you want to keep.

    </Highlight>

1.  **Remove $TOOLKIT_SHORT binaries**

    Manually remove the $TOOLKIT_SHORT files from your $PG installation directory.

    Find your $PG library directory:

    <Tabs label="Find library directory" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    pg_config --pkglibdir
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    pg_config --pkglibdir
    ```

    </Tab>

    <Tab title="Windows" label="windows">

    ```powershell
    pg_config --pkglibdir
    ```

    </Tab>

    </Tabs>

    Remove $TOOLKIT_SHORT library files:

    <Tabs label="Remove library files" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    sudo rm $(pg_config --pkglibdir)/timescaledb_toolkit*.so
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    sudo rm $(pg_config --pkglibdir)/timescaledb_toolkit*.so
    ```

    <Highlight type="note">

    On macOS, you may also need to remove `.dylib` files:

    ```bash
    sudo rm $(pg_config --pkglibdir)/timescaledb_toolkit*.dylib
    ```

    </Highlight>

    </Tab>

    <Tab title="Windows" label="windows">

    ```powershell
    del "C:\Program Files\PostgreSQL\<version>\lib\timescaledb_toolkit*.dll"
    ```

    </Tab>

    </Tabs>

    Find your $PG extension directory:

    <Tabs label="Find extension directory" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    pg_config --sharedir
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    pg_config --sharedir
    ```

    </Tab>

    <Tab title="Windows" label="windows">

    ```powershell
    pg_config --sharedir
    ```

    </Tab>

    </Tabs>

    Remove $TOOLKIT_SHORT extension files:

    <Tabs label="Remove extension files" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    sudo rm -rf $(pg_config --sharedir)/extension/timescaledb_toolkit*
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    sudo rm -rf $(pg_config --sharedir)/extension/timescaledb_toolkit*
    ```

    </Tab>

    <Tab title="Windows" label="windows">

    ```powershell
    rmdir /s "C:\Program Files\PostgreSQL\<version>\share\extension\timescaledb_toolkit*"
    ```

    You may need Administrator privileges to delete these files.

    </Tab>

    </Tabs>

1.  **Restart $PG**

    <Tabs label="Restart PostgreSQL" persistKey="source-os">

    <Tab title="Linux" label="linux">

    ```bash
    sudo systemctl restart postgresql
    ```

    </Tab>

    <Tab title="macOS" label="macos">

    ```bash
    brew services restart postgresql@<version>
    ```

    </Tab>

    <Tab title="Windows" label="windows">

    Open Services (press `Win + R`, type `services.msc`, and press Enter).
    Find the PostgreSQL service, right-click it, and select `Restart`.

    </Tab>

    </Tabs>

</Procedure>
