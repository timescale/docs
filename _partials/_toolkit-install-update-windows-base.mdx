## Prerequisites

To follow this procedure:

- [Install $TIMESCALE_DB on Windows][windows-install].

## Install $TOOLKIT_LONG

<Procedure>

1.  Download the latest $TOOLKIT_SHORT Windows installer from the [TimescaleDB Toolkit releases page][toolkit-releases].

1.  Run the installer and follow the installation wizard.

1.  **Restart the $PG service**

    Open Services (press `Win + R`, type `services.msc`, and press Enter).
    Find the PostgreSQL service, right-click it, and select `Restart`.

1.  **Connect to your database**

    ```powershell
    psql -U postgres -d <database_name>
    ```

1.  **Create the $TOOLKIT_SHORT extension**

    At the `psql` prompt:

    ```sql
    CREATE EXTENSION timescaledb_toolkit;
    ```

</Procedure>

## Update $TOOLKIT_LONG

Update $TOOLKIT_SHORT by installing the latest version and running `ALTER EXTENSION`.

<Procedure>

1.  Download the latest $TOOLKIT_SHORT Windows installer from the [TimescaleDB Toolkit releases page][toolkit-releases].

1.  Run the installer to update to the latest version.

1.  **Restart the $PG service**

    Open Services (press `Win + R`, type `services.msc`, and press Enter).
    Find the PostgreSQL service, right-click it, and select `Restart`.

1.  **Connect to your database**

    ```powershell
    psql -U postgres -d <database_name>
    ```

1.  **Update the $TOOLKIT_SHORT extension**

    At the `psql` prompt:

    ```sql
    ALTER EXTENSION timescaledb_toolkit UPDATE;
    ```

    <Highlight type="note">

    For some $TOOLKIT_SHORT versions, you might need to disconnect and reconnect active
    sessions.

    </Highlight>

</Procedure>
