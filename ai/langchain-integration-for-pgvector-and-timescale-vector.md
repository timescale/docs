# LangChain integration for pgvector, pgvectorscale, and pgai

[LangChain][langchain] is a popular framework for development applications powered by LLMs. pgai on $CLOUD_LONG has a native LangChain integration, enabling you to use it as a vector store and leverage all its capabilities in your applications built with LangChain.

Here are resources about using pgai on $CLOUD_LONG with LangChain:

- [Getting started with LangChain and pgvectorscale][getting-started-with-langchain-and-pgvectorscale]: You'll learn how to use $PGAI_LONG for (1) semantic search, (2) time-based vector search, (3) self-querying, and (4) how to create indexes to speed up queries.
- [$PG Self Querying][pg-self-querying]: Learn how to use $PGAI_LONG with self-querying in LangChain.
- [Learn more about pgai on $COMPANY and LangChain][learn-more-about-pgai-on-company-and-langchain]:  A blog post about the unique capabilities that pgai on $CLOUD_LONG brings to the LangChain ecosystem.
